# Client Strive

Client Strive est une application Angular conçue pour gérer différents modules, notamment les employés, les projets clients, et les rôles, tout en offrant une navigation sécurisée grâce à des gardes d'authentification.

## Fonctionnalités

- **Authentification :** Gestion de l'accès aux différentes parties de l'application avec un `authGuard`.
- **Gestion des employés :** Ajout, édition, et suppression des informations des employés.
- **Projets clients :** Suivi des projets assignés aux clients.
- **Rôles :** Administration des rôles pour les utilisateurs.
- **Layouts dynamiques :** Navigation structurée avec un composant de mise en page.

## Installation

1. Clonez ce dépôt :
   ```bash
   git clone https://github.com/votre-utilisateur/client-strive.git
   ```

2. Installez les dépendances :
   ```bash
   npm install
   ```

3. Lancez l'application :
   ```bash
   ng serve
   ```
   L'application sera disponible sur `http://localhost:4200`.

## Technologies utilisées

- **Framework :** Angular 18
- **Styling :** CSS/Bootstrap
- **Gestion des routes :** Angular Router
- **Services :** Services Angular pour la gestion des données
